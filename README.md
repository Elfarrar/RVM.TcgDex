# RVM.TcgDex

C# SDK for the [TCGdex](https://tcgdex.dev) API — Pokémon TCG cards, sets, series, prices and
images, in 18 languages. Free API, no key required.

> **Status: under construction.** Nothing is published on NuGet yet. Version 1.0.0 will follow the
> same API shape as the official TCGdex SDKs (`tcgdex.Card.GetAsync("swsh3-136")`).
